ESTUDO SEM INTERNET

O DadosLab vai com você.

Extraia o pacote, abra a pasta no VS Code e inicie index.html com Live Server. Os materiais, a ficha e os scripts MySQL estão incluídos. Para executar SQL, use o servidor e o cliente MySQL disponíveis no laboratório. Os PDFs também podem ser lidos separadamente.
