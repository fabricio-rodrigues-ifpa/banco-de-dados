ESTUDO SEM INTERNET

O DadosLab vai com você.

Extraia o pacote, abra a pasta no VS Code e inicie index.html com Live Server. O portal, a ficha, PDFs e bases SQL estão incluídos. O diagnóstico não exige conexão; a prática de DML usa MySQL e Workbench já preparados no PC. Os PDFs também podem ser lidos separadamente.

Baixar pacote do aluno ↓Prepare o Live Server antes de ficar sem internet. Ele exibe o portal. Para executar SQL, use o Workbench conectado ao MySQL. Links externos exigem conexão. Não há envio automático das respostas.Como abrir e entregar ↗
