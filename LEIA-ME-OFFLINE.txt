DADOSLAB - BANCO DE DADOS COM MYSQL - Prof. Fabrício Rodrigues
1. Extraia todo o pacote para uma pasta do computador ou pendrive.
2. Abra a pasta no VS Code e index.html com Live Server previamente instalado.
3. A primeira aula está em aulas.html?id=aula-01 e a ficha em diagnostico.html.
4. Responda F1 a O3 antes de consultar scripts ou referências. Baixe o TXT inicial.
5. Depois abra laboratorio.html, a área de prática MySQL.
6. O ZIP de prática contém somente 01-base-mysql.sql e 02-diagnostico.sql.
7. MySQL Server executa SQL. Workbench ou phpMyAdmin é o cliente do servidor.
8. Use a conexão e o esquema fictício de estudo indicados pelo professor.
9. Execute a base uma vez em esquema vazio, com orientação do professor.
10. Escreva P1 a P3 no cliente MySQL ou VS Code. Salve seu SQL identificado.
11. Live Server exibe o portal. O pacote não instala nem inclui MySQL Server.
12. Sem acesso ao MySQL, escreva SQL e previsões e indique que não executou.
13. Complete a ficha, escolha cópia final, baixe o TXT e entregue junto do inicial e do SQL.
14. As páginas não salvam automaticamente nem enviam respostas ao professor.
15. PDFs e arquivos locais funcionam sem internet; referências externas precisam de conexão.
16. Para executar SQL sem internet, o MySQL deve estar disponível no computador ou rede local.
