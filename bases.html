Bases SQL para praticar no MySQL

Comece pela biblioteca da aula. World e Sakila são complementares, com origem identificada e instruções próprias.

Antes de importar

Abra o MySQL Workbench e a conexão indicada pelo professor. É preciso ter acesso a um servidor MySQL e permissão para criar os esquemas de treino. O Workbench é o cliente; o Live Server não executa SQL.

Os passos abaixo usam o editor SQL do Workbench 8. Os nomes de botões podem variar em outras versões. Nos downloads, leia os avisos antes de executar. Reimportar recria dados de treino e apaga alterações feitas neles.

1. Biblioteca · base principal da aula

Uma tabela, seis registros fictícios e quatro colunas. Todos os exemplos dos slides usam esta base.

Baixar prática · apenas 2 SQL ↓Baixar só a base .sql ↓Baixar só a prática .sql ↓
  1. Extraia o ZIP e conecte-se ao MySQL pelo Workbench.
  2. Use File → Open SQL Script para abrir 01-base-dml.sql.
  3. Leia o aviso. O script cria dadoslab_dml e recria somente livros dentro desse esquema. Execute o arquivo inteiro uma vez, sem seleção.
  4. Atualize Schemas. Confira o resultado das consultas finais: banco atual dadoslab_dml, total 6.
  5. Abra 02-pratica-dml.sql. Execute USE dadoslab_dml;. Depois selecione e execute apenas a instrução indicada na aula.
  6. Responda nos comentários do SQL e salve como aula02-dml-TURMA-NOME.sql. Entregue o arquivo ao professor na aula.
USE dadoslab_dml;
SELECT DATABASE() AS banco_atual;
SELECT COUNT(*) AS total FROM livros;

Durante a prática: o botão de executar seleção executa tudo quando não há seleção. Selecione só o comando desejado ou use a opção de executar a instrução sob o cursor. Consulte, altere e confira. Não execute a prática inteira de uma vez.

Para reiniciar, salve sua prática e execute novamente 01-base-dml.sql. Isso restaura os seis registros iniciais e perde as alterações feitas nessa tabela fictícia.

2. World · países, cidades e idiomas

Boa opção para consultas complementares. São dados históricos de exemplo, não estatísticas atuais. A cópia didática contém City, Country e CountryLanguage, com as letras maiúsculas preservadas.

Baixar World para MySQL ↓
  1. Extraia o pacote e leia FONTES-E-LICENCAS.txt.
  2. Abra world-aula.sql no editor do Workbench. Leia o aviso: recria as três tabelas somente em dadoslab_world.
  3. Execute o arquivo inteiro e atualize Schemas. A importação pode levar mais tempo que a biblioteca.
  4. Confira: 4.079 cidades, 239 países e 984 registros de idiomas por país.
  5. Execute a consulta abaixo. Ela lista as cinco cidades brasileiras com maior população registrada nessa base histórica.
USE dadoslab_world;
SELECT Name, Population
FROM City
WHERE CountryCode = 'BRA'
ORDER BY Population DESC, ID
LIMIT 5;

Esta cópia foi obtida no repositório oficial MySQL, convertida de latin1 para UTF-8 e preparada com um esquema separado. Manual do World ↗

3. Sakila · locadora

Base com filmes, atores, clientes e empréstimos. Tem relações, views, rotinas e gatilhos; é indicada para exploração posterior. Não é necessário importá-la para concluir a Aula 02.

Baixar Sakila para MySQL ↓
  1. Extraia o pacote e leia a origem e as licenças.
  2. Abra e execute primeiro 01-sakila-estrutura.sql. Ele recria o esquema de treino dadoslab_sakila e apaga alterações anteriores desse esquema.
  3. Depois abra e execute 02-sakila-dados.sql, que preenche as tabelas. Não inverta a ordem.
  4. Atualize Schemas e confira 200 atores e 1.000 filmes com as consultas abaixo.
USE dadoslab_sakila;
SELECT COUNT(*) AS atores FROM actor;
SELECT COUNT(*) AS filmes FROM film;
SELECT actor_id, first_name, last_name
FROM actor
ORDER BY actor_id
LIMIT 10;

Esta é uma cópia de exemplos mantida no repositório MySQL, com o nome do esquema adaptado. Os avisos de licença BSD estão preservados nos SQL. Manual do Sakila ↗

Se aparecer um erro

  • Sem conexão: conferir com o professor o servidor e os dados da conexão.
  • 1046 ou tabela não encontrada: confirmar o script de preparação e executar o USE do esquema correto.
  • 1062: identificador duplicado; não repetir o INSERT já executado.
  • 1175: conferir WHERE usando o id, antes de mudar a configuração de atualização segura.
