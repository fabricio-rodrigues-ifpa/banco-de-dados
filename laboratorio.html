BANCO DE DADOS / MYSQL

Prática da biblioteca em MySQL

Use o MySQL Server disponível no laboratório, pelo Workbench, phpMyAdmin ou cliente já utilizado pela turma. Esta página orienta a prática e prepara o arquivo da tentativa; ela não executa SQL nem se conecta ao servidor.

Abertura dos arquivos

  1. Guarde a cópia inicial do diagnóstico antes de consultar os scripts.
  2. Baixe e extraia o ZIP: 01-base-mysql.sql e 02-diagnostico.sql.
  3. Abra o cliente MySQL e a conexão de estudo indicada pelo professor. A conta e o esquema são os do laboratório.
  4. Com orientação do professor, execute 01-base-mysql.sql uma vez em um esquema de estudo vazio. O script cria tabelas InnoDB e carrega dados fictícios. Se não houver permissão para criar o esquema, o professor indica um esquema individual e ajusta o cabeçalho.
  5. Abra 02-diagnostico.sql e escreva suas consultas. No Workbench, confira o trecho selecionado antes de executar. Salve o arquivo da tentativa.

VS Code e Live Server

Você pode editar os arquivos SQL no VS Code. O Live Server exibe a cópia offline do portal; os comandos SQL devem ser executados no MySQL. Sem acesso ao servidor, escreva as consultas, preveja os resultados e registre “não executado”.
